# 時程表產生器 timeschedule

在瀏覽器裡排甘特式時程表的小工具。單一 `index.html`，不需安裝、不需後端，放上 GitHub Pages 就能用。

## 功能

- **時間軸**：日／週／月三種單位切換
  - 週模式可選「每月固定 4 週」（1–7、8–14、15–21、22–月底）或「日曆週（週一起）」
  - 週標籤可顯示 1、2、3、4 或起始日（11/1）
  - 日模式可顯示星期、週末底色
- **專案**：一張表可放多個專案，每個專案一種顏色，左側標籤與圖示同色；標題下方自動顯示專案圖例，可一鍵依專案排序
- **橫列**：任務、舉辦日、分組標題自由新增、複製、排序、刪除
- **圖示類型**
  - 期間（橫條）
  - 單日（圓點）
  - 舉辦日（菱形）
  - 截止日（三角）
  - 分組標題（整列分隔）
- **右側直欄**：自由新增、改名、調寬，三種欄位類型
  - 文字（負責人、備註…）
  - 進度圓餅（在圖上點一下切換 0→25→50→75→100%）
  - 日期（依任務自動顯示 11/15–11/19）
- **直接操作**
  - 拖曳橫條移動、拖兩端改起訖
  - 按住圖上任務標籤或側欄任務上下拖曳，調整順序
  - 右鍵任務（標籤、橫條、側欄）：改顏色（專案）、類型、上下移、複製、刪除
  - 雙擊任務標籤改名；標題、軸標題、欄名、文字欄可直接點來改
- **介面**：側欄只列專案與任務，點任務（或點圖上的標籤）才展開細節；版面、外觀、右側欄位、匯出設定集中在「設定」
- **外觀**：時間軸主色、月份列底色可自訂；標籤文字依底色自動選黑或白；格線、今天標示、圖例、橫條內文字可開關
- **保存與輸出**
  - 自動暫存在瀏覽器（同一台電腦重開仍在）
  - 儲存／開啟 JSON（換電腦、分享、備份）
  - 下載 PDF：直接產生 PDF 檔（不經列印視窗），圖表等比縮放填滿頁面；可選 A4／A3、方向（自動／橫／直）、延展填滿（自動加大列距或欄寬貼合紙張比例）、圖上標示日期（起始日／起訖日）、是否保留今天線
  - 仍可改用瀏覽器列印視窗（文字可選取）
- 復原／重做（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z）

## 使用

直接用瀏覽器開 `index.html`，或部署到 GitHub Pages：

1. Repo → **Settings** → **Pages**
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save
3. 約一分鐘後可在 `https://<帳號>.github.io/timeschedule/` 使用

下載 PDF 需要連網（第一次會載入 html-to-image 與 jsPDF）。若改用列印視窗而背景色沒出來，勾選列印選項中的「背景圖形」。

## JSON 格式（節錄）

```json
{
  "title": "年會籌備時程",
  "unit": "week",            // day | week | month
  "weekMode": "month4",      // month4 | iso
  "start": "2026-11-01",
  "end": "2026-12-31",
  "projects": [
    { "id": "p1", "name": "活動執行", "color": "#1c1c1a" }
  ],
  "columns": [
    { "id": "c1", "name": "負責人", "type": "text", "width": 130 },
    { "id": "c2", "name": "狀態", "type": "status", "width": 70 }
  ],
  "rows": [
    { "id": "r1", "name": "交稿與預錄回覆", "type": "bar", "project": "p1",
      "start": "2026-11-15", "end": "2026-11-19",
      "fields": { "c1": "議程窗口", "c2": 25 } }
  ]
}
```

`type`：`bar`（期間）、`dot`（單日）、`diamond`（舉辦日）、`flag`（截止日）、`section`（分組標題）。顏色由所屬專案決定。舊版（無 `projects`）的檔案開啟時會自動轉成單一專案。
