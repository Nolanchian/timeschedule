# 時程表產生器 timeschedule

在瀏覽器裡排甘特式時程表的小工具。單一 `index.html`，不需安裝、不需後端，放上 GitHub Pages 就能用。

## 功能

- **時間軸**：日／週／月三種單位切換
  - 週模式可選「每月固定 4 週」（1–7、8–14、15–21、22–月底）或「日曆週（週一起）」
  - 週標籤可顯示 1、2、3、4 或起始日（11/1）
  - 日模式可顯示星期、週末底色
- **橫列**：任務、舉辦日、分組標題自由新增、複製、排序、刪除
- **圖示類型**
  - 期間（橫條）
  - 單日（圓點）
  - 舉辦日（菱形）
  - 截止日（三角）
  - 分組標題（整列分隔）
- **右側直欄**：自由新增、改名、調寬，三種欄位類型
  - 文字（負責人、備註…）
  - 進度圓餅（在圖上點一下切換 0→25→50→75→100%）
  - 日期（依任務自動顯示 11/15–11/19）
- **直接操作**：拖曳橫條移動、拖兩端改起訖；圖上的標題、軸標題、任務名、欄名、文字欄都能直接點來改
- **外觀**：6 組配色預設，主色／表頭／標籤底色／標籤文字色可自訂；格線、今天標示、橫條內文字可開關
- **保存與輸出**
  - 自動暫存在瀏覽器（同一台電腦重開仍在）
  - 儲存／開啟 JSON（換電腦、分享、備份）
  - 匯出 PDF（A4 橫、A3 橫、A4 直，可自動縮成單頁）
- 復原／重做（Ctrl/⌘+Z、Ctrl/⌘+Shift+Z）

## 使用

直接用瀏覽器開 `index.html`，或部署到 GitHub Pages：

1. Repo → **Settings** → **Pages**
2. Source 選 **Deploy from a branch**，Branch 選 `main`、資料夾 `/ (root)`，按 Save
3. 約一分鐘後可在 `https://<帳號>.github.io/timeschedule/` 使用

匯出 PDF：按「匯出 PDF」→ 列印視窗的目的地選「另存為 PDF」。若背景色沒出來，勾選列印選項中的「背景圖形」。

## JSON 格式（節錄）

```json
{
  "title": "年會籌備時程",
  "unit": "week",            // day | week | month
  "weekMode": "month4",      // month4 | iso
  "start": "2026-11-01",
  "end": "2026-12-31",
  "columns": [
    { "id": "c1", "name": "負責人", "type": "text", "width": 130 },
    { "id": "c2", "name": "狀態", "type": "status", "width": 70 }
  ],
  "rows": [
    { "id": "r1", "name": "交稿與預錄回覆", "type": "bar",
      "start": "2026-11-15", "end": "2026-11-19", "color": "",
      "fields": { "c1": "議程窗口", "c2": 25 } }
  ]
}
```

`type`：`bar`（期間）、`dot`（單日）、`diamond`（舉辦日）、`flag`（截止日）、`section`（分組標題）。`color` 留空則用主色。
